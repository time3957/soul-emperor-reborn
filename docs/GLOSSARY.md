# GLOSSARY — ชื่อเฉพาะและศัพท์

| คำที่ใช้ | ความหมาย / วิธีใช้ |
|---|---|
| ฟงชาง | พระเอกยุคปัจจุบันและนามจักรพรรดิในอดีต; อย่าเรียก “จักรพรรดิ” ผ่าน POV ฟงชางก่อนจำได้ |
| ตี้ | เพื่อนสนิทฟงชาง; ใช้ชื่อตามต้นฉบับ ไม่สลับชื่อเอง |
| หลินเสวี่ย | นักศึกษาผู้มีศักยภาพสูง ผู้รอดชีวิตจาก S-3 |
| หลินไท่ | อดีตมือขวาจักรพรรดิ ผู้ทรยศ |
| เซียะหลิง | อดีตคนรักและผู้ทรยศ ผู้ถือเศษผลึกจักรพรรดิ |
| WSC | สภาประสานพลังวิญญาณโลก — ให้ใช้ชื่อไทยนี้สม่ำเสมอ |
| S-3 | สถานีฝึกมิติซ้อน รุ่นที่ 3; ฝึกด้วยร่างจริง |
| Ascension Resonance | คลื่นสะท้อนจากเหตุระดับสูงที่กระทบ S-3; *ต้นกำเนิดยังไม่ยืนยัน* |
| จุดชีพจร | จุดสำคัญของเส้นทางเดินพลังในร่างกาย |
| การเดินลมปราณ | การหมุนเวียนพลังวิญญาณตามวงจร |
| พลังปนเปื้อน | พลังที่ผิดสมดุลหรือเป็นอันตรายต่อสิ่งมีชีวิต/เครื่องมือ |
| ก้อนพลังดำ | สิ่งผิดปกติในอกฟงชาง; ผู้เขียนรู้ว่าเป็นเศษแก่น แต่ตัวละครยังไม่รู้ |
| โลกวิญญาณ | โลกชั้นที่ผู้เฝ้าศิลาปรากฏ |
| โลกเซียน | โลกชั้นสูงที่ยังไม่มีรายละเอียดเชิงกติกา |
| มิติสวรรค์ชั้นที่เก้า | กรอบฉากอำนาจจักรพรรดิในอดีต |
| โซน 17 | นิคมอุตสาหกรรมร้าง เขตปนเปื้อนระดับ 2; บท 9 |

**หมายเหตุ:** ตัวเลขระดับพลัง การจัดขั้นสำนัก และคำเรียกพลังต่างภพ ยังไม่เป็นมาตรฐานที่ล็อก หากสร้างภายหลังต้องอัปเดตตารางนี้พร้อมระบบพลัง
