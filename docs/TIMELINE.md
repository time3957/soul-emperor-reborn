# TIMELINE — เส้นเวลาโลกและเนื้อเรื่อง

**หน่วยเวลา:** `Y0` = ปีที่พลังวิญญาณเริ่มฟื้นคืนทั่วโลก; **Y23** = เวลาปัจจุบันของบทที่ 1 เป็นต้นไป ปีปฏิทินคริสต์ศักราชยังไม่กำหนด เพื่อไม่สร้างความขัดแย้งในอนาคต

## A. ประวัติศาสตร์โลก (Canon กับรายละเอียดประกอบ)

| เวลา | เหตุการณ์ | สถานะ |
|---|---|---|
| อดีตในชั้นสวรรค์ (ไม่ระบุระยะห่าง) | จักรพรรดิฟงชางถูกคนสนิทเก้าคนหักหลัง; เผาแก่นจักรพรรดิ; เศษจิตไปเกิดใหม่บนโลก | ยืนยันจากบทนำ; **ไม่กำหนด** ความต่างของเวลากับโลก |
| ก่อน Y0 (ไม่กำหนดปี) | ผู้ทรยศหนึ่งคนเตรียมโครงการเปิดเส้นพลังโลกเพื่อเพาะผู้รับคำสาป ค่ายกลและเครือข่ายที่ใช้ยังไม่กำหนด | **Canon ผู้เขียน; ไม่ใช่เหตุที่ตัวละครยุคปัจจุบันทราบ** |
| Y0 | พลังวิญญาณคืนสู่โลกพร้อมปรากฏการณ์บนท้องฟ้า ผู้มีการตอบสนองผิดปกติเริ่มปรากฏ; **เหตุลับคือผู้ทรยศหนึ่งคนจงใจเปิดเส้นพลังที่หลับใหล** | เหตุการณ์สาธารณะยืนยัน; ต้นเหตุ **Canon ผู้เขียนแต่ยังไม่เฉลย** |
| Y0–Y2 | วิกฤตปนเปื้อน สัตว์/พืชกลายสภาพ พลังรบกวนโครงสร้างพื้นฐาน ประสานกู้ภัยไม่ทัน; เครือข่ายลับเริ่มมีโอกาสสังเกตผู้ตอบสนองต่อพลัง | ภูมิหลังและ **ความตั้งใจฝ่ายผู้ทรยศระดับผู้เขียน** |
| Y1–Y23 | โครงการลับเฝ้าคัดกรองและรอให้ผู้ฝึกเติบโตเพื่อเป็นผู้รับเศษคำสาปหลายระลอก; **ยังไม่ทราบยอดผู้รับจริงหรือจำนวนพิธีที่เกิดแล้ว** | **Canon เป้าหมายของแผน ไม่ใช่สถิติผู้เสียหาย** |
| Y3–Y6 | นักวิทยาศาสตร์กับสำนักโบราณร่วมตรวจสอบ/สร้างวิธีฝึกปลอดภัย เกิดตลาดเครื่องมือพลัง | ภูมิหลัง ไม่ล็อกวันที่ |
| **Y7** | ขยายเครือข่ายประสานงานฉุกเฉินเป็น WSC เพื่อประสานภัยข้ามพรมแดนและมาตรฐาน | กำหนดสำหรับฉบับนี้ |
| Y8–Y10 | พัฒนา/เริ่มใช้งานสถานีฝึกมิติซ้อน S-3; ณ Y23 มีประวัติใช้งาน **มากว่าสิบปีโดยประมาณ** | ให้รักษาความสอดคล้อง: เริ่มใช้ราว Y9 |
| **Y18** | มาตรฐานศักยภาพและแนวทางจัดสรรอาชีพถูกปรับครั้งใหญ่ ผู้คะแนนต่ำเสียทางเลือกมากขึ้น | เหตุการณ์ประวัติศาสตร์ **ไม่ใช่อายุฟงชาง** และไม่ใช่ความหมายของชื่อบท 1 |
| **Y20** | ฟงชางอายุประมาณ 18 ปี เริ่มเรียนวิศวกรรมพลังวิญญาณปีหนึ่ง และพบปัญหาเส้นชีพจรหลักเชื่อมต่อไม่สมบูรณ์ | อนุมานจากอายุ 21 ปีในปีสี่ ณ Y23; ไม่ใช่เวลาปัจจุบัน |
| **Y23** | ฟงชาง **อายุ 21 ปี**, เรียนมหาวิทยาลัยปี 4, ขัดข้องจุดชีพจรมาสามปี, มีผลประเมินไม่ผ่านซ้ำ | เวลาปัจจุบัน; ชื่อบท 1 “ปีที่ยี่สิบเอ็ดแห่งการลืมตา” อ้างอายุฟงชาง |
| **Y23 — เหตุลับระดับผู้เขียน** | ผู้ทรยศหนึ่งคนทดลองคลาย/ผ่องถ่ายคำสาปจนสายพันธะเก้าเส้นสั่นพ้องเป็น Ascension Resonance; **ทั้งเก้ารู้ว่าใครทดลองและทำอะไร** แต่ไม่มีผู้ใดรู้จากเหตุนี้ว่าฟงชางกลับมาเกิดใหม่; เซียะหลิงภายหลังการโต้แย้งรู้สึกคุ้นเคยเพียงแวบเดียว | **ฉากย้อนหลังที่จะเล่าภาค 4–5; ไม่ปรากฏในภาค 1 และยังไม่ระบุผู้ลงมือ** |

## B. ลำดับเหตุการณ์ในเล่มหนึ่ง

> ตารางนี้ใช้ **ค่ามาตรฐานใหม่ V2.4** อ้างอิง [POWER_SYSTEM.md หัวข้อ 5A](POWER_SYSTEM.md); **novel/ บท 1–30 ปรับเลขและกติกาหลักแล้ว** แต่ยังมีงานเกลาสำนวนและขยายฉาก

| เวลาอ้างอิง | ตอน | เหตุการณ์หลัก |
|---|---|---|
| วัน 0 (เช้า) | บท 1 | ฟงชางสอบพลัง: **8 SPU, เดินลมปราณครบ 0/3 รอบ** (เกณฑ์ใบรับรองพื้นฐาน 25 SPU + 3 รอบ; ซิงก์ต้นฉบับแล้ว); ตี้ดูแล |
| วัน 0 (บ่าย) | บท 1 | ฟงชางเฝ้าระบบ S-3 รุ่นสาม (คัดกรองจากความเสถียรของปราณ ไม่ใช่เลข SPU ตายตัว); Ascension Resonance จากภายนอกทำให้สนามเข้มข้นและจุดตรึงผิดปกติ; ฟงชางหยิบชุดปรับแรงดันบำรุงรักษา ฝ่าช่องฉุกเฉินย้อนเข้าทางบริการเพื่อช่วยหลินเสวี่ย ชุดเสื่อมสภาพและเขาบาดเจ็บหนัก |
| ประมาณวัน +2 | บท 2 | ฟงชางฟื้นในโรงพยาบาล; คังสอบถามและพบจุดชีพจรเปิดผิดคาด |
| คืนถัดมาในช่วงรักษา | บท 3 | หลินเสวี่ยมีอาการพิษปนเปื้อน; ก้อนดำดูดพลังผิดปกติ; พยาบาลเข้าช่วย |
| ประมาณสัปดาห์ที่ 2 | บท 4 | ได้กลับหอโดยแพทย์กำหนดข้อจำกัด; เริ่มรู้สึกถึงการไหลเวียนใหม่ |
| ช่วงฟื้นตัวหลังจากนั้น | บท 5–6 | ตำราทฤษฎีเริ่มเข้าใจ; ช่วยตี้ปรับท่าฝึก; ผลการฝึกของตี้กลายเป็นข่าว |
| วันจันทร์ (ยังไม่ล็อกสัปดาห์) | บท 7 | ประเมินพิเศษ; เผชิญเหอหยวน; ฟงชางแพ้ตามเกณฑ์แต่แสดงไหวพริบผิดสังเกต |
| หลังบท 7 | บท 8 | สถานีภาคสนามเบื้องต้น; ฟงชางควบคุมการหมุนเวียนได้ละเอียด ทั้งที่พลังยังต่ำ |
| ตามเหตุการณ์บท 8 | บทแทรก 8A | **WSC เท่านั้น** สอบสวนฟงชางกับเหตุ S-3 แยกแฟ้มกัน พบเส้นสัญญาณสั้น ๆ ดูคล้ายเบี่ยงเข้าหาทางบริการใกล้จุดพบฟงชาง แต่ข้อมูลขาดและ **ยังระบุต้นเหตุ/เจตนา/เป้าหมายไม่ได้**; เครื่องตรวจหลายทวีปจับคลื่นหลักได้พร้อมกัน; **ไม่มีฉากโลกวิญญาณ/เซียะหลิงในภาค 1** |
| หลังบทแทรก | บท 9 | ออกตรวจเขตปนเปื้อนระดับ 2 โซน 17; เฉิน/ตี้/หมิงเจ๋อ/อวี้หลานร่วมกลุ่ม; ถอนตัวสำเร็จ |
| วันพฤหัสบดีหลังภาคสนาม (ยังไม่ระบุสัปดาห์) | บท 10 | คังกับผู้แทนโครงการเจรจากับฟงชาง; ลงนามเข้าร่วม WSC ในสถานะนักศึกษาฝึกงาน |
| **วันศุกร์ถัดจากบท 10** | **บท 11** | กลับมหาวิทยาลัย; ยืนยัน WSC ไม่ยกเว้นเกณฑ์ใบรับรองพื้นฐาน 25 SPU/3 รอบ; ยื่นคำร้องแผนเรียนและฝึก; หลินเสวี่ยชวนร่วมโครงงานแยกวัดปริมาณ–คุณภาพ; คังแจ้งปฐมนิเทศ (ยังไม่ออกภารกิจหลังลงนาม) |

| หลังบท 11 | บท 12–14 | เริ่มฝึกพลังระดับต่ำ ทำโครงงานเครื่องวัดกับหลินเสวี่ย และอภิปรายมาตรฐานกับเหอหยวน |
| ช่วงภารกิจ WSC | บท 15–18 | สถานีริมคลอง พบหัววัด/ข้อมูลผิดปกติ; ฟงชางเกิดอาการชาและปรับการฝึก |
| หลังฝึกชดเชย | บท 19–20 | ฟงชางวัด **23 SPU** เดินได้ **1/3 รอบ** ยังสอบไม่ผ่าน; พบคำสั่งที่ซ่อนค่าพีก |
| ช่วงเตรียมงานสาธิต | บท 21–25 | จ้าวอี้ให้ข้อมูลคนงานโซน 17; WSC ประชุมหลายฝ่าย; ห้องวิจัยหลินเสวี่ยตรวจซ้ำ; พบอัปเดตระบบหลังปิดงาน |
| วันงานสาธิตและหลังเหตุ | บท 26–29 | ต้องอพยพผู้คน; ตี้หัวไหล่บาดเจ็บ ฟงชางมีอาการชาจนต้องหยุด; ทีมช่างแก้ระบบ; สอบสวนการรับรองและรหัสเก่า |
| เวทีนำเสนอหลังเหตุ | บท 30 | วิจัยถูกพิจารณาต่อยอด, ฟงชางได้รับอนุมัติแผนสอบชดเชยแต่ยังไม่ผ่าน; หลินเสวี่ยเลือกคู่ทีมเองและเริ่มยอมรับว่าแอบชอบ; เปิดปมแข่งระหว่างสถาบัน |

## C. ความต่อเนื่องที่ต้องรักษา

- เวลาหลัง S-3 ไม่ให้แขนหักหายทันที; เมื่อฝึกหลังพักฟื้นต้องคำนึงถึงคำสั่งแพทย์
- ห้ามย้อนกลับไปกล่าวว่า WSC เพิ่งก่อตั้งใน Y18: **Y18 คือการปรับมาตรฐาน ไม่ใช่ปีเริ่มองค์กร** 
- เหตุการณ์ฟื้นคืน Y0 (ผู้เขียนรู้ว่าคือแผนผู้ทรยศเปิดเส้นพลังโลก) และคลื่นภายนอกที่ทำให้ S-3 พังใน Y23 เป็น **สองเหตุการณ์แยกกัน** ไม่มีหลักฐานว่ามีต้นเหตุเดียวกัน
- ยอดผู้รับพิธีระดับหลักล้านคือ **ขนาดที่โครงการต้องการในอนาคต** ไม่ยืนยันว่ามีเหยื่อแล้วเท่าใด และผู้คนใน Y23 ไม่รู้โครงการลับ
- บทแทรก 8A หลังบทนำอยู่กับ **มุม WSC บนโลกมนุษย์** เท่านั้น; ฉากผู้เฝ้าศิลา/เซียะหลิงเดิมเก็บเป็นร่างพักไว้ใน [DEFERRED_SCENES](DEFERRED_SCENES.md) เพื่อดัดแปลงเป็นฉากภาคหลัง
- **Y23 ความลับผู้เขียน:** การทดลองคลายคำสาปเป็นต้นเหตุคลื่น แต่โลกมนุษย์ยังมีเพียงหลักฐานทางเครื่องตรวจ; แยกจาก Y0 ที่เป็นโครงการเปิดเส้นพลังคนละเหตุการณ์ และไม่ล็อกว่าเป็นผู้ลงมือคนเดียวกัน
- **เซียะหลิง:** ช่วง Y23 ไม่ได้รับพิกัดและไม่ส่งลูกน้องตามหาเพราะความรู้สึกแผ่วเบา; เมื่อภาคหลังพลังฟงชางชัดขึ้นจึงอาจเริ่มตรวจสอบ/ใช้ผู้ติดตามในเงื่อนไขที่รองรับได้
- **อัตราพลังฟงชาง:** ภาค 1 คง **8 → 11 → 23 SPU / 0/3 → 1/3** และยังสอบไม่ผ่าน; ภาค 2 อัตราบ่มเพาะเพิ่มเร็วผิดธรรมดาเมื่อร่างกายรับไหว; ภาค 2 ปลาย–ภาค 3 เริ่มได้รับการประเมินว่ามีศักยภาพระดับอัจฉริยะจากผลฝึกจริง ยังไม่ล็อกตัวเลขหรือขั้นใหม่
- วัน/เดือน/ปีตามปฏิทินจริงยังเว้นไว้ ไม่เดาเติมเอง
