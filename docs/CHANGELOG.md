# CHANGELOG — การพัฒนาต้นฉบับ

## 2026-11-24 — อนุมัติกรอบโครงเรื่องระยะยาว

- กำหนด **6 ภาค เป้าหมาย 150–180 บท** เป็นแนวทางจัดจำนวนเรื่องและจังหวะ (ขยับได้เมื่อเนื้อเรื่องต้องการ)
- บันทึกสถานะ **บท 1–10 = มีต้นฉบับแล้วแต่ยังต้องตรวจ/รีไรต์**, บท 11–30 = รอแต่ง 20 บท, บท 31–150/180 = โครงภาคยังไม่เขียน
- แตกโครงเบื้องต้นบทที่ 11–20 ให้มีเป้าหมาย ความขัดแย้ง และผลที่ตามมา; บท 21–30 วางเป็นสองช่วง
- ล็อกทิศทางพระเอกว่าเป็น **เศษเสี้ยววิญญาณของจักรพรรดิฟงชางคนเดียวกัน** ไม่ใช่สองวิญญาณยึดร่าง; ฟื้นพลัง ความเข้าใจ และความทรงจำคนละจังหวะ
- แก้ข้อความเดิมที่เรียกบท 10 ว่า “จบเล่มที่ 1” ให้เป็น **จุดพักต้นฉบับระหว่างภาค 1**
- **ไม่มีการแก้ไฟล์เนื้อเรื่องใน `novel/` รอบนี้**

## 2026-11-24 — วางโครงสร้าง Repository ครั้งแรก

- แยกบทนำ, บทที่ 1–10 และบทแทรกเป็นไฟล์ `novel/` แยกบท รวม 12 ไฟล์
- ขยายช่วงต้นบทที่ 1 ให้เห็นประวัติการกลับมาของพลังวิญญาณ เหตุจำเป็นต้องก่อตั้ง WSC ผลทางเศรษฐกิจ ชีวิตคนระดับศักยภาพต่ำ และเป้าหมายฟงชางก่อนเข้าสอบ
- จัด Timeline ให้ปี Y18 เป็นปีปรับเกณฑ์ศักยภาพ ส่วนเรื่องดำเนินใน Y20; WSC ตั้งก่อน Y18
- สร้าง Story Bible, Timeline, World, Power System, Characters, Outline, Continuity, Style Guide และ Glossary
- กำหนด `novel/` เป็นแหล่งเนื้อเรื่องหลัก ไม่แก้ไฟล์รวมเล่มด้วยมือ
- เพิ่มสคริปต์สร้างไฟล์รวมเล่มที่อ่านจากบทจริงตามสารบัญ

## สถานะ

ยังเป็น **ต้นฉบับเล่ม 1 ระหว่างขัดเกลา**; การวางระบบระดับบ่มเพาะเต็มรูปแบบ/แรงจูงใจผู้ทรยศ/เหตุ Y0 ไม่ควรกล่าวว่าเสร็จสิ้น
