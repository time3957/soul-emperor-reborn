# CHANGELOG — การพัฒนาต้นฉบับ

## 2026-11-25 — ล็อกโครงสร้างสังคม/พลังโลกมนุษย์ V2.4 ในเอกสารอ้างอิง

- กำหนด SPU เป็นค่าพลังส่วนบุคคลที่ WSC วัดได้ **แยกจากขั้นบ่มเพาะ**; ช่วง 50–99 ยังไม่เคลือบกายอย่างมั่นคง, 100+ เริ่มฝึกเสริมกายได้ และระดับสูงเน้นชื่อระดับมากกว่าตัวเลข
- แยกคณะวิทยาการบ่มเพาะจากคณะวิศวกรรมพลังวิญญาณ: จบคณะบ่มเพาะขั้นต่ำ 25 SPU พร้อมทักษะพื้นฐาน, จบวิศวกรรมไม่บังคับ SPU, ใบรับรองบ่มเพาะพื้นฐาน 25 SPU/3 รอบ, ใบอนุญาตภาคสนาม E ขั้นต่ำ 50 SPU พร้อมสอบจริง
- ปรับค่าฟงชางใน **เอกสารอ้างอิงเท่านั้น** เป็น 8 → 11 → 23 SPU; ยังไม่ผ่านใบรับรองพื้นฐาน จบวิศวกรรมตามวิชาการได้; รักษา S-3 เป็นสถานีฝึกมิติซ้อนรุ่นสาม
- สเกลมหาวิทยาลัยตัวอย่าง 1,000 คนต่อรุ่น (บ่มเพาะ 300/วิศวกรรม 700), รวมสี่ปี ~4,000 คน และอาจารย์ 200 คน; อัจฉริยะรุ่นเยาว์ ~2–3 คนต่อเมือง ณ เวลาเดียวกัน ไม่ใช่ต่อปี; **หลินเสวี่ยเป็นหัวกะทิ ไม่ใช่อัจฉริยะระดับเมือง**
- อัปเดต POWER_SYSTEM, STORY_BIBLE, CONTINUITY, TIMELINE, OUTLINE โดย **ไม่แตะ novel/ บท 1–30**; ตัวเลข 0.8/1.1/2.3/15 ในต้นฉบับเป็นค่าร่างเก่าที่ต้องซิงก์ภายหลัง รวมทั้งข้อความผูกการจบวิศวกรรมกับการสอบบ่มเพาะ

## 2026-11-24 — แก้คำอธิบายอาการพลังปนเปื้อนในบท 3

- ปรับคำพูดหลินเสวี่ยให้บอกอาการจากการสัมผัสของผู้ฝึกว่าเหมือนมีสิ่งแปลกปลอมไหลสวนในเส้นชีพจร แทนการใช้คำว่า “พลังไหลย้อน” เป็นชื่ออาการที่ยืนยันแล้ว
- เปลี่ยน “ยากดการไหลย้อน” เป็นแพทย์ตรวจพบพลังปนเปื้อนตกค้าง ให้ยาบรรเทาอาการและเฝ้าตรวจค่าพลัง โดยไม่ระบุว่าเป็นยารักษาพลังไหลย้อนโดยตรง
- คงเหตุการณ์อาการทรุด การช่วยเหลือ และผลตรวจผิดปกติหลังฟงชางสัมผัส; แก้เฉพาะ `novel/03-unreported.md` กับ Changelog

- คงบริบทที่หลินเสวี่ยมีอาการป่วยและทรุดลงหน้าเตียง รวมทั้งบทสนทนาและเหตุการณ์ถัดไป; แก้เพียงบท 3 และ Changelog ไม่แก้บทอื่น

- ระบุว่าค่ายกลชิงแก่นดัดแปลงจากวิชาป้องกันตำหนักที่ฟงชางเคยสอน; ปรับบทสนทนาเซียะหลิงเพื่อเน้นความขัดแย้งทางศีลธรรม โดยไม่กล่าวถึง “คนที่อยู่หลังม่าน” ในบทนำฉบับนี้
- คงจังหวะลงมือเผาแก่นอย่างฉับพลัน ความเสียหายของราชันทั้งเก้า ราคาวิญญาณดับสูญ และการไม่เฉลยวิธีรอดของฟงชาง
- แก้เฉพาะบทนำและบันทึก Changelog ไม่ขยายการแก้ไขไปบทหรือเอกสารอื่น


## 2026-11-24 — เร่งจังหวะเผาแก่นและบันทึกประตูต้นกำเนิดในเอกสารอ้างอิง

- คืนคำพูดเดิม **“ยกเว้นวิธีรับมือกับคนที่ไม่เหลืออะไรให้เสีย”** ใน `novel/00-prologue.md` และให้ฟงชางลงมือเผาแก่นทันทีโดยไม่มีบทสนทนาหรือการตั้งรับยืดยาว
- ราชันทั้งเก้ารับแรงสังหารฉับพลันด้วยปราการ/เครื่องรางติดตัวและสัญชาตญาณการรบ จึงรอดอย่างบาดเจ็บหนัก แต่ไม่มีเวลาวางแผนเตรียมใหม่ก่อนแรงระเบิด; ราคาวิญญาณดับสูญและปมการรอดของฟงชางยังเหมือนเดิม
- บันทึก **ประตูต้นกำเนิด เสาหลักเก้าภพ ราคาความเสียหายและเหตุที่ต้องใช้แก่นจักรพรรดิ** ใน `docs/STORY_BIBLE.md` สำหรับผู้เขียนเท่านั้น; จัดกฎความต่อเนื่องใน `docs/CONTINUITY.md`
- **ไม่อธิบายรายละเอียดประตูในบทนำ และไม่แตะบทที่ 1 หรือบทอื่น**


## 2026-11-24 — ฉากเผาแก่นเป็นการลากผู้ทรยศทั้งเก้าตกตายไปด้วยกัน

- ปรับ `novel/00-prologue.md` ให้การเผาแก่นของฟงชางมี **เจตนาสังหารผู้ทรยศทั้งเก้าไปพร้อมกับตน** ไม่ใช่การทิ้งคำสาปอย่างเดียว
- ผู้ทรยศทั้งเก้าใช้วิชาป้องกันแตกต่างกัน รับแรงระเบิดได้จนรอด แต่บาดเจ็บหนัก รากฐานสั่นคลอน และตราคำสาปฝังผ่านเศษแก่นที่ชิงไป; ไม่อ้างว่าบาดเจ็บ/ฝีมือเท่ากัน
- รักษาราคาวิญญาณดับสูญของฟงชางและไม่เฉลยการรอดในบทนำ; อัปเดต Story Bible, Power System และ Continuity ตามขอบเขตฉากนี้
- เกลาถ้อยคำ “ลายเซ็นต้นกำเนิด” ที่หลงเหลือในบทนำให้เป็น “ร่องรอยปราณต้นกำเนิด”


## 2026-11-24 — เกลาสองประโยคบทนำเรื่องการหลีกทางและคำสัตย์

- เซียะหลิงขอให้ฟงชาง **แบ่งแก่นจักรพรรดิและหลีกทางให้เปิดประตู** โดยคงประเด็นว่าคำสัญญา “ไม่มีใครต้องตาย” ถูกฟงชางตั้งคำถามถึงชีวิตผู้คนเก้าภพ
- เปลี่ยนศัพท์เทคนิค “ลายเซ็นพลัง” เป็น **“รอยประทับปราณจากพิธีสัตย์สาบาน”** เพื่อให้เข้ากับสำนวนชั้นสวรรค์และค่ายกลคำสัตย์เดิม
- เปลี่ยนเฉพาะสองประโยคใน `novel/00-prologue.md`; ไม่แก้กลไกคำสาปหรือเฉลยการรอด


## 2026-11-24 — ปรับบทนำให้ชัดเรื่องการชิงแก่นและจุดจบของจักรพรรดิ

- ปรับ `novel/00-prologue.md` คงเหตุการณ์และบทสนทนาแกนเดิม เพิ่มลำดับที่ผู้ทรยศได้เศษแก่นก่อนฟงชางเลือกเผาแก่น และภัยของการได้แก่นสมบูรณ์
- ระบุราคาเป็น **วิญญาณดับสูญถาวร** หากเผาถึงต้นกำเนิด และฟงชางรู้/ยอมรับโดยไม่วางแผนหนี; การช่วยของจิตแห่งแก่นต้องเกิดก่อนการสูญสิ้นและเป็นความลับระดับผู้เขียน
- ไม่เขียนชัดในบทนำว่าฟงชางรอดหรือกลับมาเกิดใหม่ จบฉากด้วยตำหนักแตกและบัลลังก์ว่าง
- เกลาสรรพนามและคำประกาศ `ตราบาปแห่งการทรยศ` ให้กลไกคำสาปส่งผลผ่านเหตุการณ์ ไม่ใช่บรรยายอธิบายอย่างเดียว
- อ่านทวนบท 1 เพื่อเทียบปริศนาแล้วคงต้นฉบับเดิม; อัปเดต Story Bible, POWER_SYSTEM, CONTINUITY และ Editorial Report


## 2026-11-24 — กำหนดความต่างของสเกลพลังเก้าราชันและจักรพรรดิ

- กำหนด **ราชันสวรรค์ = สมญา/ฐานันดร ไม่ใช่ระดับพลังที่ทำให้ทั้งเก้าเท่ากัน**; อธิบายระบบ WSC เป็นการวัดตัวเลขที่ตรวจจับได้ ซึ่งไม่ใช่ระดับบ่มเพาะโบราณ
- เพิ่มกรอบภาวะพลังขั้นสูงแบบไม่ผูกตัวเลข: สัมผัสกฎ → สถาปนาขอบเขต → ครองกฎ → แปรกฎ → ประสานต้นกำเนิด โดยยังไม่สรุประบบชื่อขั้นครบทุกโลก
- กำหนดแฟ้มผู้ทรยศเก้าคน R01–R09 ให้ถนัดต่างกัน (ทัพ, ผนึก, กายเกราะ, มิติ, ค่ายกล, จิตมายา, อสนี, ชีวิต, ดารา) โดยมีชื่อจริงเพียง **หลินไท่/เซียะหลิง** และเลขรหัสไม่ใช่อันดับความเก่ง
- แยก **พลังในอดีต / ความสามารถภายใต้คำสาป / ระดับที่อาจกู้คืนได้**; ฟงชางอดีตเข้าถึงต้นกำเนิด แต่ปัจจุบันยังอยู่ภายใต้ค่า 0.8 → 2.3 และผลสอบไม่ผ่าน 15/3
- **คงปม Y0:** ไม่ระบุผู้ทรยศที่ริเริ่มพิธีรับเคราะห์ล้านวิญญาณ ไม่เปิดเผยชื่ออีกเจ็ดรายหรือกำลังที่ฟื้นได้จริง และไม่แก้ `novel/` ในรอบนี้
- อัปเดต `docs/POWER_SYSTEM.md`, `docs/STORY_BIBLE.md`, `docs/CHARACTERS.md`, `docs/CONTINUITY.md` และ CHANGELOG ให้ตรงกัน

## 2026-11-24 — อนุมัติแผนฟื้นพลังโลกเพื่อเพาะผู้รับคำสาปจำนวนมหาศาล

- WSC ยังเป็นองค์กรที่เกิดจากงานกู้ภัยจริง แผนลับสามารถแทรกซึมบางส่วนของสำนัก/บริษัท/ข้อมูลโดยไม่กล่าวหาทุกหน่วยงาน; ยังไม่ตัดสินว่าโซน 17 หรือไท่เหิงเกี่ยวกับพิธี
- อัปเดต Story Bible, Power System, Continuity, Outline, Timeline และ World ให้ตรงกัน; **ไม่แก้ไฟล์ต้นฉบับ novel/** และไม่เฉลยความลับให้ตัวละครก่อนเวลา
