# CHANGELOG — การพัฒนาต้นฉบับ

## 2026-11-25 — เพิ่มการบาดเจ็บขณะช่วยนักศึกษาก่อนติดอยู่ใน S-3

- ปรับเฉพาะฉากอุบัติเหตุบท 1: คลื่น Ascension Resonance จากภายนอกทำให้โครงสร้างฝึกปะทุ **ระลอกแรก** (ไม่ใช่แกนมิติยุบช่วงจบ) หลินเสวี่ย **92 SPU** ใช้ม่านปราณชั่วครู่ป้องกันนักศึกษา 2 คนจากเศษโลหะ ส่งทั้งคู่ไปจุดอพยพ ก่อนโดนคลื่นสะท้อนเข้าหัวไหล่ซ้าย/ทรวงอกและถูกเศษโลหะกระแทกต้นแขน
- เมื่อพยายามถอนตัว เสาค้ำจากจุดตรึงเสียสมดุลหักพับหนีบข้อเท้าขวากับรางพื้น การฝืนยกเสาเกิดปราณสะท้อนย้อนซ้ำบนร่างที่บาดเจ็บ แต่เธอยังมีพลังเหลือช่วยประคองตอนฟงชางใช้คานงัดเฉพาะจุด
- ซิงก์ `docs/CHARACTERS.md`, `docs/POWER_SYSTEM.md`, `docs/STORY_BIBLE.md` และ `docs/CONTINUITY.md` โดยคงกติกา 92 SPU, ไม่ใช้ 3/3 รอบวัดหลินเสวี่ย และไม่เปลี่ยนเหตุการณ์แกนยุบสุดท้าย/แขนหักฟงชาง/บท 2–3

## 2026-11-25 — เพิ่มเหตุหลินเสวี่ยติดใน S-3 และตัดเกณฑ์ 3/3 รอบออกจากโปรไฟล์

- ฉากบทที่ 1: ระบุ **เสาค้ำเสียรูป หนีบข้อเท้าขวากับรางพื้น และยังเชื่อมกับจุดตรึงมิติที่ผิดเฟส** การฝืนใช้ปราณยกโครงโลหะเกิดแรงสะท้อนย้อนเส้นชีพจร เธอยังทำงานได้บางส่วนแต่ไม่อาจยกเสาทั้งต้นได้อย่างปลอดภัย; ฟงชางใช้ **คานงัดเฉพาะรอยหนีบ** และหลินเสวี่ยช่วยประคอง ไม่ใช่พระเอกมีกำลังมากกว่า
- ปรับเอกสาร `docs/CHARACTERS.md`, `docs/POWER_SYSTEM.md`, `docs/STORY_BIBLE.md`, `docs/CONTINUITY.md` ให้สอดคล้องกับฉากและค่าพลัง **92 SPU**
- **ยกเลิกการระบุ 3/3 รอบของหลินเสวี่ย:** วงจร 3 รอบเป็นแบบทดสอบใบรับรองบ่มเพาะ **ระดับพื้นฐาน/ผู้เริ่มฝึก** เท่านั้น ไม่ใช่ค่าพลังประจำตัวหรือเกณฑ์ความชำนาญระดับหลินเสวี่ย; เกณฑ์ของฟงชาง **25 SPU + 3 รอบ** ยังใช้กับการสอบพื้นฐานตามเดิม
- ไม่เปลี่ยนต้นเหตุคลื่นภายนอก การบาดเจ็บของฟงชาง การตรวจผู้ฝึกเข้า S-3 หรือผลสอบบทอื่น

## 2026-11-25 — ปรับค่าพลังหลินเสวี่ยให้เหมาะกับระดับนักศึกษา (แทน 136 SPU)

- **Canon ล่าสุด:** หลินเสวี่ย **92 SPU** ณ Y20 ก่อน S-3; เดินปราณพื้นฐาน **3/3 รอบอย่างเสถียร**, อยู่ช่วง **50–99 SPU ผู้ฝึกหัด** และเป็นหัวกะทิของคณะจากทักษะควบคุมที่โดดเด่น ไม่ใช่อัจฉริยะระดับเมืองหรือผู้บ่มเพาะระดับต้น (100–299 SPU)
- แก้ค่าที่เคยระบุ 136 SPU ใน `docs/CHARACTERS.md`, `docs/POWER_SYSTEM.md`, `docs/STORY_BIBLE.md` ให้ตรงกันทั้งหมด และแก้คำอธิบายความสามารถ/ใบอนุญาตให้ตรงสเกลใหม่; **ค่าพลัง 92 SPU ไม่เท่ากับมีใบอนุญาต E** และยังไม่ถึงเกณฑ์ D
- เก็บรายการ CHANGELOG เดิมเป็นประวัติและระบุว่าสถานะเลข 136 ถูกยกเลิกแล้ว ไม่เขียนทับประวัติ; ยังไม่แก้เนื้อเรื่องใน `novel/` เพราะต้นฉบับไม่เคยระบุค่าพลังหลินเสวี่ยเป็นตัวเลข

## 2026-11-25 — เพิ่มโปรไฟล์และค่าพลังอ้างอิง «หลินเสวี่ย» (ตัวเลข 136 SPU ถูกแก้ไขในรายการถัดมา)

- ขยาย `docs/CHARACTERS.md` โดยใช้เหตุการณ์ที่ปรากฏในบท 1–30 คุมบุคลิก ความสามารถ การวิจัย บทบาทใน S-3 และความสัมพันธ์กับฟงชาง; แยกข้อมูลเดิมออกจากตัวเลขที่เพิ่งกำหนดใหม่
- **กำหนด Canon เพิ่ม ณ Y20 ก่อนอุบัติเหตุ S-3:** หลินเสวี่ยมีพลัง **136 SPU** เดินปราณพื้นฐาน **3/3 รอบอย่างเสถียร** อยู่กลุ่ม **100–299 SPU ผู้บ่มเพาะระดับต้น** เป็น **หัวกะทิของคณะ** ไม่ใช่อัจฉริยะระดับเมือง
- ตัวเลข SPU ไม่เท่ากับใบอนุญาตภาคสนาม D (เกณฑ์พลัง 100 SPU ยังต้องมีการสอบ/รับรองจริง), ไม่ทำให้ทนคลื่นผิดความถี่และซากทับได้; หลัง S-3 ยังไม่มีผลตรวจตัวเลขใหม่ตามต้นฉบับ
- อัปเดต `docs/POWER_SYSTEM.md` และ `docs/STORY_BIBLE.md` ให้ใช้ค่าตัวเลขอ้างอิงตรงกัน; **ไม่แก้ฉากนิยาย** เพื่อไม่ให้เปลี่ยน Canon โดยยัดผลตรวจย้อนลงในบทที่ยังไม่มีฉากตรวจพลังเธอ

## 2026-11-25 — ขยายทะเบียนตัวละคร «ตี้» จากเหตุการณ์ภาค 1

- ขยายโปรไฟล์ตี้ใน `docs/CHARACTERS.md` ให้เป็นเอกสารอ้างอิงแบบอ่านได้ด้วยตัวเอง: สถานะ/ภาพจำ บุคลิกและข้อบกพร่อง ความสัมพันธ์และสำนวนบทสนทนา ลำดับพัฒนาการบท 1–30 รวมถึงหลักการเขียนต่อ
- อ้างอิงเหตุการณ์ที่เกิดแล้ว: ช่วยฟงชางด้วยขนมปังและอาหาร เฝ้าโรงพยาบาล/จดบทเรียน ฝึกปราณจากท่าและลมหายใจ ดูแลเมื่อมีอาการชา ช่วยอพยพจนหัวไหล่บาดเจ็บและยังต้องฟื้นฟู
- แยก `ยืนยันในต้นฉบับ` จาก `แนวทางแต่งต่อ` และ `ยังไม่กำหนด`; ไม่เพิ่มค่าพลัง SPU อายุ ชื่อเต็ม ครอบครัว หรือความสามารถเฉพาะใหม่เป็น Canon และไม่ได้แก้ฉากนิยาย

## 2026-11-25 — ปรับบทพูดตี้ให้เป็นการกินรองท้องก่อนข้าวเที่ยง

- แก้เฉพาะบทที่ 1: ตี้ยื่นขนมปังและน้ำให้ฟงชางกินรองท้องหลังสอบ แล้วไปกินมื้อเที่ยงที่โรงอาหารตามลำดับเหตุการณ์เดิม
- ให้ฟงชางกัดขนมปังหนึ่งคำและดื่มน้ำ เพื่อเชื่อมของที่ได้รับกับการกระทำโดยไม่เปลี่ยนฉากถัดไป

## 2026-11-25 — แยกอายุฟงชาง 18 ปีออกจากเวลาโลก 20 ปีในฉากเปิด

- บทที่ 1 ใช้เวลา **Y20 (20 ปีหลังพลังวิญญาณฟื้นคืน)** เป็นปัจจุบัน และระบุว่าฟงชาง **อายุ 18 ปี** เพื่อให้ชื่อ “ปีที่สิบแปดแห่งการลืมตา” หมายถึงอายุของตัวละครอย่างชัดเจน
- เก็บการประกาศมาตรฐานของ WSC เมื่อสองปีก่อน (**Y18**) ไว้เป็นเหตุการณ์ในอดีต ไม่ใช้คำว่า “ปีที่สิบแปดหลังการฟื้นคืน” เป็นประโยคแรก จึงไม่ทำให้ผู้อ่านเข้าใจผิดว่าบทดำเนินใน Y18
- ซิงก์ TIMELINE / STORY_BIBLE / CHARACTERS / CONTINUITY; บันทึกประเด็นที่ต้องให้เหตุผลภายหลังเกี่ยวกับการเรียนมหาวิทยาลัยปีสี่ขณะอายุ 18 ปี โดยไม่สร้าง Canon ระบบรับเข้าก่อนวัยเอง
- ไม่เปลี่ยนผลสอบ ระบบพลัง ลำดับอุบัติเหตุ S-3 หรือเนื้อหาอื่นในบท

## 2026-11-25 — เรียบเรียงบทที่ 1 ตามฉบับเปิดด้วยผลสอบและเก็บ Canon สำคัญ

- ใช้ฉบับเรียบเรียงใหม่จากผู้เขียนเป็นโครงเปิด: Hook `ปีที่อนาคตถูกใส่ตัวเลข` → ผลสอบ 8 SPU / 0 จาก 3 รอบในฉากแรก → บทสนทนาตี้ → เหตุเครื่องกรองพลังริมทาง → โรงอาหาร → S-3; ระบุชัดว่าปัจจุบันเป็นสองปีหลังประกาศมาตรฐานในปี Y18
- แก้ความต่อเนื่อง: ตี้พูดหลังสอบตกตามเวลา, รถรับส่งสายวงแหวนไปโรงอาหารข้ามเขตมหาวิทยาลัย, ผู้โดยสารถูกให้ลงรอจึงได้ยินบทสนทนาเรื่องช่างซ่อม; เชื่อมภาพช่างบาดเจ็บเข้ากับการตัดสินใจช่วยหลินเสวี่ย
- ให้ฟงชางกวนกลับคนดูถูกด้วยความมั่นใจด้านวิศวกรรม (`ฉันต้องอยู่ข้างนอก คอยดูว่าพวกที่มีรอบพลังครบจะทำเครื่องพังหรือเปล่า`) โดยไม่เปลี่ยนเหตุขัดข้องว่ามาจากคลื่นภายนอก
- คืนรายละเอียดสำคัญจากต้นฉบับ GitHub ได้แก่ ข้อจำกัดชีพจร, โครงสร้างมหาวิทยาลัยและ WSC, การฝึก S-3, ตู้ชุดปรับแรงดันของช่าง, ทางบริการ, ตัวกรองเสื่อม, การกู้ภัยและอาการบาดเจ็บ; ไม่กำหนดเวลาตัวกรองตายตัวหรือทำให้ชุดเพิ่ม SPU
- คงความลับก้อนพลังดำและเหตุที่รอดชีวิตไม่เฉลยตรง ๆ; รักษาช่วงจบและผลสอบไม่ผ่านตาม Canon
- แก้เฉพาะ `novel/01-awakening-year-18.md` จาก 29,860 เป็น 32,353 อักขระ ก่อนบันทึกผ่านการตรวจตำแหน่ง Hook/ผลสอบ/มุกกวน/เหตุ S-3 และข้อความต้องห้าม; ไม่แก้บทอื่น

## 2026-11-25 — กระจายประวัติศาสตร์โลกเพื่อปรับจังหวะเปิดบทที่ 1

- ปรับเฉพาะ `novel/01-awakening-year-18.md`: หลัง Hook ให้เข้าสู่ฉากสถานีกลางและความสัมพันธ์ฟงชาง–ตี้ทันที แทนการเล่าภูมิหลังโลกต่อเนื่องก่อนเกิดเหตุการณ์
- ย้ายประวัติศาสตร์เดิม **ครบ 22 ย่อหน้าโดยไม่ตัดเนื้อหา** ไปเชื่อมกับฉากรถโดยสาร มหาวิทยาลัย ระบบ WSC/ใบรับรอง และพื้นหลังสถานี S-3 พร้อมเพิ่มประโยคเชื่อมเพื่อให้ลำดับการอ่านลื่นไหล
- ไม่เปลี่ยนผลสอบ 8 SPU / 0 รอบ กติกาความพร้อม S-3 ชุดปรับแรงดัน การช่วยหลินเสวี่ย เหตุคลื่นภายนอก บาดเจ็บ หรือนิมิตท้ายบท และไม่แก้บทอื่น
- ตรวจเปรียบเทียบก่อน–หลัง: บทเพิ่มจาก 29,108 เป็น 29,860 อักขระ; ช่วงตั้งแต่การตรวจประตูฝึกหลัก S-3 จนจบบทคงข้อความเดิมทั้งหมด

## 2026-11-25 — ปรับกติกา S-3 เป็นการตรวจความพร้อมทางสรีระ ไม่ล็อกตัวเลข SPU

- เปลี่ยนการเข้าใช้พื้นที่ฝึก S-3 จากขั้นต่ำ **25 SPU / 3 รอบ** เป็นการตรวจความเสถียรของปราณ การโคจร การตอบสนองต่อแรงกด และความพร้อมของเส้นชีพจร ฟงชางถูกปฏิเสธเพราะพลังต่ำและชีพจรติดขัดจริง ไม่ใช่แพ้ตัวเลขอย่างเดียว
- ยืนยัน S-3 เป็นสนามปราณเข้มข้นที่เลียนแบบดินแดนศักดิ์สิทธิ์โบราณ ช่วยขัดเกลาและบีบอัดปราณระหว่างการฝึก แต่ **ไม่เพิ่ม SPU โดยอัตโนมัติ**
- เพิ่มชุดปรับแรงดันสำหรับช่างซ่อมบำรุง ตัวกรองมีความจุจำกัด สวมแล้วเข้าทางบริการในสภาพปกติได้ภายใต้การอนุญาต; ฟงชางฝ่าช่องอพยพฉุกเฉินย้อนเข้าทางบริการเพื่อช่วยหลินเสวี่ยโดยพลการ ชุดร้อนและเสื่อมสภาพเมื่อสนามพัง
- อัปเดตฉากบท 1, การตรวจหลังเหตุบท 2 และ POWER_SYSTEM / STORY_BIBLE / CONTINUITY / TIMELINE โดยคงผลบาดเจ็บ เหตุคลื่นภายนอก และปริศนาเดิม
- **หมายเหตุ:** เกณฑ์ 25 SPU / 3 รอบยังคงใช้กับ *ใบรับรองทักษะบ่มเพาะพื้นฐาน* แต่ไม่ใช่กฎเข้า S-3

## 2026-11-25 — ปรับ Canon S-3 และขยายฉากอุบัติเหตุ

- ปรับบทนำ–บทที่ 30 รวมบทแทรก (32 ไฟล์) เฉพาะจุดจำเป็นให้ตรงกับสเกล **8 → 11 → 23 SPU**, ใบรับรองพื้นฐาน **25 SPU/3 รอบ**, ใบอนุญาต E **50 SPU**, สถานะสองคณะ และหลินเสวี่ยระดับ **หัวกะทิ**
- เพิ่ม S-3 เป็นสถานีฝึกมิติซ้อนรุ่น 3 สำหรับทดสอบแรงกด การควบคุมปราณ ภูมิประเทศ และถอนตัว ไม่ใช่เครื่องเพิ่มพลัง; พื้นที่มิติหลักขั้นต่ำ 25 SPU/3 รอบ ส่วนฝึกขั้นต้นแยกจากกัน

## 2026-11-24 — อนุมัติแผนฟื้นพลังโลกเพื่อเพาะผู้รับคำสาปจำนวนมหาศาล

- อัปเดต Story Bible, Power System, Continuity, Outline, Timeline และ World ให้ตรงกัน; **ไม่แก้ไฟล์ต้นฉบับ novel/** และไม่เฉลยความลับให้ตัวละครก่อนเวลา
