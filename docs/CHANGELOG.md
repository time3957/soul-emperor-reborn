# CHANGELOG — การพัฒนาต้นฉบับ

## 2026-11-24 — วางโครงสร้าง Repository ครั้งแรก

- แยกบทนำ, บทที่ 1–10 และบทแทรกเป็นไฟล์ `novel/` แยกบท รวม 12 ไฟล์
- ขยายช่วงต้นบทที่ 1 ให้เห็นประวัติการกลับมาของพลังวิญญาณ เหตุจำเป็นต้องก่อตั้ง WSC ผลทางเศรษฐกิจ ชีวิตคนระดับศักยภาพต่ำ และเป้าหมายฟงชางก่อนเข้าสอบ
- จัด Timeline ให้ปี Y18 เป็นปีปรับเกณฑ์ศักยภาพ ส่วนเรื่องดำเนินใน Y20; WSC ตั้งก่อน Y18
- สร้าง Story Bible, Timeline, World, Power System, Characters, Outline, Continuity, Style Guide และ Glossary
- กำหนด `novel/` เป็นแหล่งเนื้อเรื่องหลัก ไม่แก้ไฟล์รวมเล่มด้วยมือ
- เพิ่มสคริปต์สร้างไฟล์รวมเล่มที่อ่านจากบทจริงตามสารบัญ
