# STYLE GUIDE — แนวทางเขียนและตรวจต้นฉบับ

## แนวและน้ำเสียง

แฟนตาซีบ่มเพาะแบบพระเอกถูกมองว่าไร้ค่าในโลกสมัยใหม่ ก่อนสถานการณ์พลิกอย่างคาดไม่ถึง แต่ **ความเก่งต้องมีเหตุและต้นทุน**; ตลกด้วยความสัมพันธ์/บุคลิก ไม่ใช่มุกคั่นอารมณ์รุนแรงทุกครั้ง

## หลักการฉาก

- **ฉากหนึ่งต้องมีเป้าหมาย–แรงต้าน–ผลที่ตามมา** และเชื่อมกับฉากถัดไป
- ปูโลกผ่านสิ่งที่ตัวละครต้องเจอ เช่น ค่าข้าว ใบรับรอง งานซ่อมสถานี เหตุผลต้องมาที่ S-3 มากกว่าเทข้อมูลเป็นหน้า ๆ
- พูดถึงองค์กร/เทคโนโลยีต้องตอบได้ว่า “ทำไปทำไม, ใครได้ประโยชน์, ใครเสียผลประโยชน์”
- บทสนทนาต้องมีคำถามและคำตอบสัมพันธ์กัน ไม่ให้ตัวละครโผล่/หาย/ได้รับข้อมูลโดยไม่มีขั้นตอน
- ย่อหน้าของนิยายให้อ่านต่อเนื่องตามจังหวะ ไม่หักหนึ่งประโยคเป็นหนึ่งย่อหน้าตลอดทั้งเรื่อง
- การกระทำที่เสี่ยงต้องมีแรงจูงใจและผลจริง ความกล้าของฟงชางไม่ทำให้เขากลายเป็นผู้ไม่มีวันกลัว

## ความต่อเนื่องและ POV

- ต้นเรื่องใช้การเล่าชิดมุมมองฟงชาง; ข้อมูลอดีตชาติให้ผู้อ่านจากบทนำและบทแทรก
- อย่าให้ตัวละครรับรู้สิ่งที่เกิดในห้องอื่น/ต่างภพโดยไร้ช่องทาง
- ฟงชาง–ตี้ ใช้สำนวนเพื่อนสนิท; เวลาอยู่กับคัง/อาจารย์ใช้ภาษาสุภาพ
- ให้หลินเสวี่ยมีวาระและการกระทำเป็นของตัวเอง; ให้คังมีหลักฐานก่อนสงสัย

- [ ] ผลของบาดเจ็บ พลัง และเวลาสอดคล้องบทก่อน

## การแก้ไฟล์

แก้เฉพาะไฟล์บทที่เกี่ยวข้อง; เมื่อเปลี่ยนข้อเท็จจริงหลายบท ให้ทำรายการผลกระทบก่อน ไม่แต่งขยายไปเรื่อย ๆ; บันทึกการตัดสินใจใน [CHANGELOG](CHANGELOG.md).

## กฎบังคับ: เพิ่มความยาวได้ แต่ห้ามลดเนื้อเรื่อง

- **รักษาต้นฉบับเดิมครบถ้วน:** ไม่ตัดฉาก เหตุการณ์ รายละเอียดสำคัญ บทสนทนา ปมที่ปูไว้ หรือพัฒนาการตัวละคร แม้จะต้องการให้จังหวะเร็วขึ้น
- **เพิ่มเพื่อให้ดีขึ้น:** เพิ่มการกระทำ บรรยากาศ บทสนทนาที่ต่อเนื่อง เหตุผลรองรับ และผลจากเหตุการณ์เดิม โดยไม่เปลี่ยนสาเหตุ/ผลลัพธ์สำคัญ
- **ห้ามทำให้สั้นลง:** ความยาวของฉบับปรับปรุงในแต่ละบทต้องไม่น้อยกว่าฉบับก่อนหน้า เว้นแต่ผู้เขียนอนุมัติให้แก้ไขเป็นกรณีเฉพาะ
- **วิธีตรวจ:** เปรียบเทียบก่อน–หลัง และยืนยันว่าเนื้อหาเดิมยังอยู่ครบตามลำดับ หากแก้ถ้อยคำที่ผิดเพื่อความถูกต้อง ต้องรักษาความหมายและรายละเอียดเดิมทั้งหมด
- **บทที่ 1:** ผู้เขียนยืนยันว่าความยาวดีแล้ว ให้รักษาเป็นบทเดียว ไม่แยกเป็นบท 1–3 ตามแผนที่เคยเสนอ
- **บทที่ 2–10:** ขยายตามลำดับและหมายเลขเดิม ไม่สลับเหตุการณ์หลักหรือแทรกบทใหม่โดยพลการ

**ขอบเขตการรีไรต์ให้กำหนดเป็นรายรอบ:** คงกฎห้ามตัด/ย่อเนื้อเรื่องกับบทที่เขียนแล้วทั้งหมด (ปัจจุบันบทนำ บทแทรก และบท 1–30) ในแต่ละรอบให้ตรวจและแก้เฉพาะตอนหรือประเด็นที่ตกลง ไม่ขยายภารกิจไปทั้งนิยายโดยไม่มีเหตุ และบันทึกสิ่งที่ยังต้องพัฒนาไว้ในรายงานแยกต่างหาก
